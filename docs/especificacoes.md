# Auto Visão Financeiro — pacote inicial para Codex

Este pacote contém **documentação de produto e engenharia**, não código executável.

## Arquivos
- `PRD.md` — visão e escopo do produto, jornadas e critérios de aceite.
- `REGRAS_NEGOCIO.md` — regras aprovadas e propostas a validar.
- `BANCO_DADOS.md` — modelo de dados proposto, invariantes e APIs sugeridas.
- `ROADMAP.md` — etapas de desenvolvimento e primeiro prompt para o Codex.
- `AGENTS.md` — instruções permanentes para o agente Codex.

## Uso no Windows/Codex
1. Extraia o ZIP em uma pasta local, por exemplo `Documentos\autovisao-financeiro`.
2. Abra essa pasta como projeto no Codex.
3. Peça: “Leia AGENTS.md e os demais documentos e comece pela Etapa 0 do ROADMAP.md”.
4. Versione os arquivos no Git quando inicializar o repositório.

O pacote mantém a distinção entre **decisões aprovadas** e **detalhes técnicos ainda propostos**.
