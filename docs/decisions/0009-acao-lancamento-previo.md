# Identificação com lançamento prévio pelo cabeçalho

O seletor Como identificar este movimento foi removido. A identificação direta permanece como formulário inicial. O botão Identificar com Lançamento Prévio fica no canto inferior direito do cartão com os dados originais do movimento e abre a busca de lançamentos existentes.

O usuário pode voltar à identificação direta por botão, preservando os dados do formulário. Movimentos já vinculados continuam exibindo o vínculo e a ação de desvincular. Nenhuma regra de baixa, validação, auditoria ou preservação do original foi alterada.
