# Período de validação: nenhuma aprovação automática

Decisão do usuário em 25/11/2026: zero aprovações automáticas de movimentos, inclusive padrões históricos unânimes, transferências próprias e Processos Automáticos.

Toda análise gera somente sugestões versionadas; nenhum reconhecimento insere identificações confirmadas. As sugestões continuam em Importar Extrato até a confirmação explícita do operador. Alta confiança (azul) e confiança que exige revisão (amarelo) não autorizam aprovação automática. Não existe uma data de reativação automática.

Padrões históricos continuam disponíveis como sugestões mesmo sem API generativa. A IA pode completar mais vínculos com evidência, preservando a prioridade de cliente específico sobre grupo. Recebimentos PIX sem cliente ou grupo têm confiança geral limitada e orientação para completar a contraparte; não se escolhe uma loja arbitrariamente.

Não modifica o extrato original nem reverte identificações anteriores ou importações históricas explicitamente confirmadas. Reavaliar dados já confirmados é uma operação distinta e auditada.
